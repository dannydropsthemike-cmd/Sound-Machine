
# Brown Noise Sound Machine

A minimal brown noise generator designed for mobile devices.

## Features

- Mathematically generated brown noise
- Continuous playback
- Volume control
- Sleep timer
- Gradual fade-out
- iPhone home screen icon
- Installable web app
- Offline app interface
- No external audio files
- No advertising

## GitHub Pages Setup

1. Create a GitHub repository.
2. Upload all project files.
3. Open Settings.
4. Select Pages.
5. Select Deploy from a branch.
6. Choose main.
7. Choose /(root).
8. Save.

Your website will be published at your GitHub Pages URL.

## iPhone Installation

1. Open the published website in Safari.
2. Tap Share.
3. Select Add to Home Screen.
4. Enable Open as Web App if available.
5. Tap Add.

## Audio

Brown noise is generated using an integrated random-noise
algorithm. It has substantially more low-frequency energy
than white noise.

No external audio files are required.

## Important iOS Note

iOS may suspend web-app audio when the app is backgrounded
or the phone locks. Background playback should be tested
on the target device before relying on it overnight.
